# Henry's ML Atlas

This is a live, work-in-progress notebook I maintain to store my thoughts and learnings as I progress through the industry.

It focuses on mechanisms, assumptions, consequences, trade-offs and experimental design choices, rather than mathematics.
I know some will dislike this, but intuition comes from understanding - not memorisation, that comes later.

AI has been used a here, as with most things these days, but as book this is primarily a resource for myself, I stand by every word.
I take pride in this resource and I share it in the hope someone finds it as useful as I do.

# My Philosophy:
The `Initial Commentary` section describes how I approach things, but to summarise: 
  - Understand >> memorise,
  - Analogy + Visual + Example -> Intuition,
  - People remember a story,
  - Jargon is gatekeeping.

# Sections Guide:

I split the content into:

  - Content: Hardware, Architectures, etc.,
  - Use Cases: Applications of the content,
  - Interviews: Getting to work on the use cases,
  - Papers: My thoughts on papers, updates as they come. Some breakthroughs may be added into the main text
